# Riyadh Real Estate: Apartments EDA & Power BI Dashboard 🏙️📊

An end-to-end data analysis project exploring apartment rental and sales listings across Riyadh, Saudi Arabia. The project covers data cleaning and feature engineering using Python, followed by an interactive dashboard built with Microsoft Power BI.

---

## 📌 Project Overview
- **Data Source**: Riyadh apartments dataset.
- **Tech Stack**: Python (Pandas, Jupyter Notebook), Microsoft Power BI, DAX.
- **Key Deliverables**:
  - `data_cleaning_riyadh_apartments.ipynb`: End-to-end data cleaning, handling missing values, and categorization.
  - `riyadh_apartments_cleaned.csv`: Cleaned and standardized dataset.
  - `Riyadh_Apartments_Dashboard.pbix`: Interactive executive reporting dashboard.

---

## 🔍 Key Insights & Features
- **Price Categorization**: Classified listings into distinct tiers: Affordable (اقتصادية), Mid-tier (متوسطة), and Luxury (فاخرة).
- **Geographical Breakdown**: Average selling price and distribution across Riyadh regions.
- **Space & Size Metrics**: Average price per square meter correlated with bedroom count.
- **Interactive Slicers**: Dynamic cross-filtering by price tier, region, and amenities (e.g., elevator availability).

---
